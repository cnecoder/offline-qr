# UI 设计(UI Design)

> 版本:v1.1,2026-10-30 定稿(紧凑小窗口重设计)。
> 实现与本文档不一致时,先改文档。

## 1. 设计原则

识别工具,路径要短:打开窗口 → (截图后)Ctrl+V → 结果已在眼前。

- **信息密度优先**:小窗口(720×540)内不留大面积空白,主内容区占满剩余高度并内部滚动
- 极简,无冗余按钮,无任何网络元素
- 现代感来自克制的分层(边框 + 圆角 + 细滚动条),不靠大留白

## 2. 布局(单页纵向三段式,flex 充满窗口)

```
┌────────────────────────────────────────┐
│  二维码识别               离线 · 本地运行 │ ← 顶栏(紧凑,~36px)
├────────────────────────────────────────┤
│ [选择图片]  拖拽图片到窗口,或 Ctrl+V 粘贴 │ ← 输入条(一行式 toolbar,卡片样式)
├────────────────────────────────────────┤
│  识别中 2/5…                             │ ← 进度行(仅批量时出现)
│ ┌────┐ https://example.com/a?b=1       │
│ │缩略│ [打开链接] [复制]                 │ ← 主内容区(flex:1,内部滚动)
│ └────┘                                 │    空态时居中显示提示 + 图标
│ ┌────┐ 未识别到二维码(灰显)            │
│ └────┘                                 │
├────────────────────────────────────────┤
│ 最近识别(3)                     清空    │ ← 历史状态条(~34px)
└────────────────────────────────────────┘
      ↑ 展开时历史列表自底部向上浮出(浮层面板,不挤压主内容)
```

- 拖拽高亮:整窗内描边(app 容器 inset box-shadow),不再依赖大 dropzone
- 生成功能后期回归时,在顶栏下引入 Tab(识别 / 生成);v1 不放可见占位

## 3. 组件规格

- **输入条**:一行式;主按钮 `[ 选择图片 ]` + 弱化提示文字"拖拽图片到窗口,或 Ctrl+V 粘贴截图";卡片样式(圆角 12px、1px 边框)
- **结果卡片**:左侧 44×44 缩略图;等宽字体文本 13px,超 2 行折叠、点击展开;操作:复制(必有)、打开链接(仅 URL),小号按钮(12px);失败卡灰显"未识别到二维码";一图多码逐条列出
- **进度行**:12px 强调色文字,批量完成即消失
- **空态**:主内容区垂直居中 — 线性 QR 图标(36px)+ 主句"识别结果会显示在这里" + 副句"粘贴、拖拽或选择含二维码的图片"
- **历史**:底部状态条(计数按钮 + 清空);展开时列表作为浮层面板向上弹出(max-height 220px,内部滚动,投影分层);点击条目回显为结果卡
- **轻提示**:底部居中胶囊"已复制",2 秒自动消失

## 4. 视觉

- 字体:system-ui / Microsoft YaHei;正文 14px,辅助 12–12.5px,结果文本 13px 等宽
- 主色:靛蓝 `#4F46E5`(深色 `#818CF8`);错误 `#DC2626` / 深色 `#F87171`
- 分层:背景 `--bg` → 卡片 `--surface` → 次级表面 `--surface-2`;1px 边框 + 圆角 12px(卡片)/ 8px(按钮、缩略图)
- 深浅色:CSS 变量两套,`prefers-color-scheme` 自动切换;v1 不做手动开关
- 间距:4/8/10/14px 紧凑刻度;主内容左右 padding 10px
- 滚动条:8px 细滚动条,圆角滑块,透明轨道
- 拖拽悬停:整窗 2px 内描边(强调色)

## 5. 窗口规格(Tauri)

- 默认 **720×540**;最小 **600×460**;可调整大小;启动居中;标题"二维码识别"
- 产品名(安装包标识):QrTool

## 6. 交互细节与空态

- 粘贴全局监听(无需聚焦任何输入框);粘贴内容非图片时忽略;非图片文件拖入时轻提示"未发现图片文件"
- 快捷键:v1 仅 Ctrl+V,不做自定义
- 可访问性:按钮可键盘聚焦,主操作带 aria-label,对比度满足 WCAG AA

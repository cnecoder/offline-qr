# UI 设计(UI Design)

> 版本:v1.0,2026-10-30 定稿。
> 实现与本文档不一致时,先改文档。

## 1. 设计原则

识别工具,路径要短:打开窗口 → (截图后)Ctrl+V → 结果已在眼前。极简,无冗余按钮,无任何网络元素。

## 2. 布局(v1 单页,无 Tab)

```
┌──────────────────────────────────────────┐
│  二维码识别               离线 · 本地运行   │ ← 顶栏:应用名 + 副标语
├──────────────────────────────────────────┤
│                                          │
│        拖拽图片到窗口任意位置              │ ← 输入区(默认态,大目标区域)
│     [ 选择图片 ]      Ctrl+V 粘贴截图     │
│                                          │
├──────────────────────────────────────────┤
│  识别中 2/5 …                             │ ← 状态行(有任务时出现)
├──────────────────────────────────────────┤
│ ┌────┐  https://example.com/a?b=1        │ ← 结果卡片列表(新 → 旧)
│ │缩略│  [ 打开链接 ] [ 复制 ]             │    URL 卡:原文 + 打开 + 复制
│ └────┘                                   │
│ ┌────┐  未识别到二维码(灰显)            │ ← 失败卡
│ └────┘                                   │
├──────────────────────────────────────────┤
│  最近识别(12)                    清空    │ ← 历史(可折叠,默认收起)
│  10-30 14:02   https://…                 │
└──────────────────────────────────────────┘
```

- 生成功能后期回归时,在顶栏下引入 Tab(识别 / 生成);v1 不放任何可见占位,仅架构上不阻塞。

## 3. 组件规格

- **输入区**:虚线边框圆角卡,高约 180px;拖拽悬停时主色高亮;文案固定三处:主按钮 `[ 选择图片 ]`、"拖拽图片到窗口任意位置"、"Ctrl+V 粘贴截图"
- **结果卡片**:左侧 64×64 缩略图(object-fit: cover);右侧等宽字体文本,超 3 行折叠、点击展开;操作:复制(必有)、打开链接(仅 URL);失败卡灰显"未识别到二维码";一图多码在卡内逐条列出,每条独立复制
- **状态行**:`识别中 n/N…`,全部完成即消失
- **历史**:默认收起并显示条数;点击条目回显为结果卡;`清空` 需确认
- **轻提示**:复制成功 → 底部居中"已复制",2 秒自动消失

## 4. 视觉

- 字体:system-ui / Microsoft YaHei;正文 15px,辅助 12–13px
- 主色:靛蓝 `#4F46E5`(深色模式 `#818CF8`);错误 `#DC2626` / 深色 `#F87171`
- 卡片:圆角 14px,1px 边框 + 极浅投影
- 深浅色:CSS 变量两套,`prefers-color-scheme` 自动切换;v1 不做手动开关
- 间距:8px 基准网格;内容区最大宽 720px 居中

## 5. 窗口规格(Tauri)

- 默认 860×720;最小 640×560;可调整大小;启动居中;标题"二维码识别"
- 产品名(安装包标识):QrTool

## 6. 交互细节与空态

- 粘贴全局监听(无需聚焦任何输入框);粘贴内容非图片时忽略
- 空态(无结果、无历史):输入区下方浅灰提示"识别结果会显示在这里"
- 快捷键:v1 仅 Ctrl+V,不做自定义
- 可访问性:按钮可键盘聚焦,主操作带 aria-label,对比度满足 WCAG AA

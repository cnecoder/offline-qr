# UI 设计(UI Design)

> 版本:v1.4,2026-11-01(配色与质感重定为 WinTab 派生暗色方案;布局结构沿用 v1.3)。
> 实现与本文档不一致时,先改文档。

## 1. 设计原则

- 识别工具,路径要短:打开窗口 → (截图后)Ctrl+V → 结果已在眼前
- 生成工具,调得深也要看得清:左表单右预览,每次改动即时反馈,可扫性徽章常驻
- 信息密度优先:小窗口内不留大面积空白;现代感来自克制的分层,不靠大留白

## 2. 布局

### 2.1 双 Tab

顶栏下为分段式 Tab:`识别 | 生成`(默认识别;记忆上次选择不引入,每次启动停在识别)。

### 2.2 识别 Tab(v1.1 布局不变)

```
┌────────────────────────────────────────┐
│  二维码识别               离线 · 本地运行 │
│ [识别] [生成]                            │
├────────────────────────────────────────┤
│ [选择图片] [屏幕选区] 拖拽 / Ctrl+V 粘贴  │
│  识别中 2/5…                             │
│ ┌────┐ https://example.com/a?b=1       │
│ │缩略│ [最新] 屏幕选区 · 11-01 18:23:45  │ ← 主内容区(flex:1,内部滚动)
│     │ ┌文本块(完成后默认全选)┐ [复制]   │
│ └────┘                                 │
├────────────────────────────────────────┤
│      (结果卡片区即识别历史,随会话滚动)   │
└────────────────────────────────────────┘
```

### 2.3 生成 Tab(两栏)

```
┌────────────────────────────────────────┐
│ [识别] [生成]                            │
├──────────────┬─────────────────────────┤
│ ▾ 内容        │                          │
│  [文本|Wi-Fi|名片]                       │
│   文本:textarea │     [二维码预览]         │
│   Wi-Fi:SSID/  │                        │
│   密码/加密/隐藏│   ✓ 可扫(徽章)         │
│   名片:姓名等   │  [保存 PNG] [保存 SVG]  │
│   纠错 L/M/Q/H │  [复制图片]              │
│ ▸ 样式        │   状态行                  │
│ ▸ Logo        │                          │
│ ▸ 导出(尺寸)  │                          │
│ 预设:■■■■■    │                          │
├──────────────┴─────────────────────────┤
│ 最近生成(2)                     清空     │ ← 生成历史状态条 + 上浮面板
└────────────────────────────────────────┘
```

- 左列表单约 300px,内部滚动;`details/summary` 分组(内容/样式默认展开,Logo/导出默认收起)
- 内容组顶部为三段模式切换:`文本 | Wi-Fi | 名片`;切换后字段区整体替换
  - Wi-Fi 字段:SSID(必填)、密码、加密(WPA/WEP/无)、隐藏网络;密码明文输入(本地工具)
  - 名片字段:姓名(必填)、手机、电话、邮箱、组织、职位、网址、地址(紧凑两列网格)
- 右列预览区垂直居中;透明背景以棋盘格纹理呈现
- 底部为生成历史状态条(与"最近识别"同款交互):点击条目恢复生成表单;识别 Tab 的"最近识别"与之相互独立

## 3. 组件规格

- **Tab**:分段控件样式(与 v1.1 按钮同语言),激活项强调色
- **表单控件**:label 12.5px 弱化色 + 控件紧凑;颜色用原生 color input(36px 方块);range 滑杆带当前值
- **预览框**:SVG 居中,最大 260×260;棋盘格背景(8px 格)体现透明
- **可扫性徽章**:`✓ 可扫`(强调色)/ `⚠ 未识别,建议调整`(错误色);样式变化后防抖 300ms 刷新;检测中显示"检测中…"
- **内容模式切换**:三段芯片(文本/Wi-Fi/名片),激活项强调色
- **生成历史**:与识别历史同款状态条/浮层;条目类型徽标 20px 圆芯片:文(text)/ Wi(wifi)/ 片(vcard);摘要单行省略;text=原文、wifi=`Wi-Fi:<ssid>`、vcard=`名片:<姓名>`
- **操作行**:保存 PNG / 保存 SVG / 复制图片;复制成功走全局轻提示
- **预设条**:5 个芯片按钮(经典 / 靛蓝圆点 / 活力渐变 / 翡翠径向 / 徽标款);点击应用对应样式(徽标款仅切换提示,引导上传 logo)
- **Logo 组**:选择图片(文件)→ 显示 32px 缩略图 + 移除;大小滑杆 15–30%;形状 方/圆
- **结果卡片**:缩略图(**正方形**,拉伸至与内容区上下缘对齐)+ 文本行;文本块默认**单行省略**(所有卡片等高),点击展开全部、点击块外收起;原生可选(拖选部分/三击全选;光标在块内时 Ctrl+A 只选本块);右侧**复制**按钮与文本块等高(强调色实心);**识别完成后默认全选文本块**
- **最新识别置顶着重**:最近完成的一条卡片排到列表最前,仅以强调色描边着重(无文字徽标);失败卡同样适用
- **清空识别记录**:**独立红色实心卡片**,与左侧功能卡片同行隔离(等高圆角矩形,白字);二次点击确认(3s 自动解除);无记录时隐藏
- **卡片 meta 行**:顺序为 **时间(年-月-日 时:分:秒)· 来源(屏幕选区/文件/拖动/粘贴)· 源文件路径(桌面端文件/拖动来源;超长省略号,悬停显示全文)· [最新]**——徽标殿后,各卡片前缀信息左对齐一致
- **结果卡片 / 历史面板**:识别 Tab 不再设"最近识别"底部状态条(结果卡片区即识别历史,识别记录不跨会话持久展示);生成 Tab 保留"最近生成"面板(沿用原交互)

## 4. 视觉(v1.4:WinTab 派生暗色方案)

- 配色参考 WinTab:中性暗色基底 + 单一强调色,整体恒为暗色(桌面工具定位)
  - 基底:背景 `#0B0C0F` / 表面 `#12141A` / 次级表面 `#0D0F14`
  - 文字:正文 `#E8EBF1` / 次级 `#9AA3B5` / 弱化 `#5B6475`;分隔线 `rgba(255,255,255,.08)`
  - 强调色:黑绿 `#35D07A`(hover `#48E08C`),实心主按钮/激活项配深色文字 `#04240F`;错误 `#FF6B6B`
  - 选中/激活态语言:accent 淡染(12%)+ inset 1px 描边(45%)
- 字体:`Segoe UI` + `Microsoft YaHei` 原生栈;结果文本 Consolas 等宽
- 圆角阶梯:4(徽章/缩略图)/ 6(按钮、输入、行)/ 8(面板、卡片)px;微动效 140ms ease-out
- 主按钮:强调色实心;次按钮:次级表面 + 中性描边,hover 淡染
- 间距:4/8/10/14px 紧凑刻度;细滚动条;拖拽整窗内描边高亮
- **主题系统**(WinTab 同款):中性基底共享、主题只换 accent——黑绿 `#35D07A`(默认)/ 黑黄 `#FBBF24`;顶栏"配色 绿/黄"一键切换,localStorage 持久化,首帧前内联脚本应用避免闪换

## 5. 窗口规格(Tauri)

- 默认 **720×540**;最小 **600×460**;可调整;启动居中;标题"二维码识别"
- 产品名:QrTool
- **整窗圆角(v1.5)**:Win10 无 DWM 圆角 → 无边框(`decorations: false`)+ 透明窗(`transparent: true`),
  网页层画 10px 圆角 + 描边 + 阴影,四周 6px 透明边;自绘标题栏(拖拽/双击最大化,`data-tauri-drag-region`),
  右上自绘 最小化/最大化/关闭(关闭悬停为危险色);构建标记移入自绘标题栏(build_info 命令);
  最大化时去圆角贴合屏幕;遮罩选区窗不受影响(全屏不透明黑)

## 6. 交互细节与空态

- 识别 Tab:粘贴全局监听(两 Tab 均可粘贴识别);非图片忽略并提示
- 生成 Tab:输入防抖 150ms 重渲染;预览 SVG 常驻(内容为空时预览区显示"输入内容后自动生成")
- 可扫性检测期间不阻塞表单操作;检测失败(引擎异常)徽章显示"⚠ 检测失败"
- 清空确认:WebView2 无原生 confirm,生成历史清空为应用内二次点击确认(3s 自动解除)
- 生成历史面板:点击面板外部自动收起;条目恢复后面板自动收起
- **全局快捷键**(桌面版,任何应用下可用):`Alt+Q` 直接发起屏幕选区识别(等价按钮);`Alt+W` 显示/隐藏主窗。被其他程序占用时自动降级并记日志;工具条提示展示 Alt+Q
- 可访问性:控件可键盘聚焦,主操作带 aria-label,对比度满足 WCAG AA

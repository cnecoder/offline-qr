# 需求文档(Requirements)

> 版本:v1.0,2026-10-30 定稿。
> 变更流程:先改本文档并 commit,再改实现;文档与实现保持一致。

## 1. 项目概述

轻量、完全离线的二维码识别小工具。v1 只做一件事:**把图片二维码识别的体验做到最好**。生成模块与摄像头扫码列入后期路线。

- 目标用户:个人用户;高频场景 = 从截图、相册图片里快速取出二维码内容
- 核心价值:离线可用、零上传隐私安全、识别准(抗模糊/倾斜)、操作路径短(粘贴即得)

## 2. 平台与形态

| 项 | 结论 |
|---|---|
| 开发/首发平台 | Windows 10/11 |
| 后期平台 | Linux、macOS(架构保留桌面三端通用;不考虑 iOS 等移动端) |
| 形态 A(主) | Tauri 2 桌面应用,NSIS 安装包 |
| 形态 B | 纯网页单文件 `dist/index.html`(file:// 直开或任意静态服务) |

## 3. v1 功能需求

### FR-1 图片输入(三条路径全打通)
- FR-1.1 文件选择:点击按钮打开系统文件对话框,可一次选择多张 `image/*`
- FR-1.2 拖拽:窗口任意位置接受拖拽,支持一次多张;非图片文件忽略并提示
- FR-1.3 粘贴:Ctrl+V 直接粘贴剪贴板中的图片(截图工作流,无需先点任何按钮)
- FR-1.4 输入即排队识别,按输入顺序处理,展示进度(n/N)

### FR-2 识别能力
- FR-2.1 引擎:zxing-wasm(ZXing-C++ 官方 WASM),码制仅 QR Code
- FR-2.2 一图多码:单张图片中的多个二维码全部识别、全部展示
- FR-2.3 识别在后台线程执行,批量识别期间界面不卡顿
- FR-2.4 识别失败明确反馈:对应图片标注"未识别到二维码",且不阻塞队列中其他图片
- FR-2.5 手机照片按 EXIF 方向解码;超大图自动降采样

### FR-3 结果处理
- FR-3.1 展示识别原文;URL 提供"打开链接";长文本折叠/展开
- FR-3.2 一键复制单条结果;复制成功有轻提示
- FR-3.3 v1 不做 Wi-Fi/vCard 等结构化解析(一律原文展示)

### FR-4 识别历史
- FR-4.1 本地保存最近 20 条(去重:重复内容置顶并刷新时间)
- FR-4.2 点击历史项回显其内容与操作
- FR-4.3 一键清空;数据仅存本机(localStorage)

### FR-5 界面
- 简体中文;跟随系统深浅色;单窗口(默认 860×720,最小 640×560)
- 细节以 docs/ui-design.md 为准

### FR-6 离线保证
- 运行期零网络请求;安装/运行不依赖任何在线服务

### FR-7 屏幕选区识别(仅桌面版)
- FR-7.1 工具栏提供"屏幕选区"入口(桌面版显示;浏览器单文件形态隐藏)
- FR-7.2 点击后截取**主显示器**画面,进入全屏遮罩:十字光标、画面暗化、拖拽出矩形选区(强调色描边)
- FR-7.3 松开即按图像像素裁剪所选区域,送入既有识别管线,结果卡名称为"屏幕选区"
- FR-7.4 Esc 取消;拖拽尺寸过小(宽或高 < 4 CSS 像素)视为取消
- FR-7.5 浏览器形态无 Tauri IPC,该功能整体不可用(按钮隐藏、遮罩窗口降级为提示文案)

### FR-8 生成二维码:深度自定义与美化(recognition-generation 分支)
- FR-8.1 双 Tab:识别 | 生成;两 Tab 共享窗口与识别管线
- FR-8.2 内容:文本/网址输入,纠错等级 L/M/Q/H
- FR-8.3 样式定制:
  - 模块形状:方块 / 圆角 / 圆点
  - 定位角(眼睛):外框与内点独立选形(方 / 圆角 / 圆),且颜色可独立设置
  - 前景:纯色,或线性/径向渐变(双色 + 角度)
  - 背景:纯色或透明;留白 0–8 模块(默认 4)
- FR-8.4 Logo 嵌入:中央图片,大小比例可调(15%–30%),方形/圆形裁剪,自动挖空覆盖区域模块
- FR-8.5 预设样式 5 种:经典黑白 / 靛蓝圆点 / 活力渐变 / 翡翠径向 / 徽标款(引导上传 logo)
- FR-8.6 导出:PNG(256–2048px 可调)/ SVG 矢量 / 复制图片
- FR-8.7 可扫性自检:每次渲染后用内置识别引擎自动试扫,徽章实时显示"✓ 可扫 / ⚠ 未识别,建议调整"
- FR-8.8 可扫性规则(渲染器强制):三个定位角恒为实心环(不随模块形状点化);logo 覆盖区域模块挖空并限制尺寸比例;留白默认 4 模块

## 4. 非功能需求

| 项 | 目标 |
|---|---|
| 安装包体积 | ≤ 8 MB(预期 4.5–7.5 MB) |
| 单张识别延迟 | 常规截图 < 300 ms |
| 隐私 | 图片与识别结果不出本机,无任何上报 |
| 健壮性 | 单张失败不影响批量队列 |

## 5. 明确不做(本批)

- 摄像头实时扫码
- 条形码等其他码制、批量导出报告、多语言、账号/云同步/自动更新、系统托盘/全局快捷键
- 屏幕选区的多显示器与全局快捷键(后期;仅主显示器 + 工具栏按钮触发)
- 生成的 Wi-Fi/vCard 内容模板与生成历史(recognition-generation 分支下一批)

## 6. 后期路线(粗粒度,逐期再细化)

1. 生成的内容模板(Wi-Fi、vCard)与生成历史(recognition-generation 分支下一批)
2. 屏幕选区增强:多显示器选区、全局快捷键触发、选区尺寸/放大镜提示
3. Linux 适配
4. macOS 适配(构建需 macOS 环境或 CI macOS runner)

> 平台节奏:全部功能先在 Windows 上验证与打磨,打磨完成后才进行 Linux / macOS 适配。
> 摄像头扫码:已从路线图移除,不做。
